Chapter 2: Processing Data
Slide 1: Chapter Introduction Processing Data
explains how to collect data from users, store it in variables, perform calculations, display results, and handle errors in C# applications. 
Slide 2: Topics (1 of 2)
 Reading input with TextBox controls; variables and data types; numeric data types; calculations; numeric input/output; number formatting; exception handling; and named constants. 
 Slide 3: Topics (2 of 2) Declaring variables as fields; using the Math class; more GUI details; and using the debugger to locate logic errors.
  Slide 4: Reading Input with TextBox Control A TextBox is a rectangular control that allows users to enter information using the keyboard. It is found in the Common Controls group of the Toolbox. Its default names are textBox1, textBox2, and so on.
   Slide 5: The Text Property The Text property stores or retrieves the text entered into a TextBox. It accepts string values. Example: textBox1.Text = "Hello"; textBox1.Clear();
    Slide 6: A First Look at Variables A variable is a storage location in memory used to hold data. A variable name represents that location. A variable must be declared before it is used. Syntax: string name; 
    Slide 7: Data Types A data type specifies the kind of data a variable can hold. Examples: string stores text; int stores whole numbers; double stores real numbers including decimals; decimal stores real numbers with greater precision and is commonly used for financial applications. Primitive data types are basic, built-in data types provided by the language.
     Slide 8: Variable Names A variable name identifies a variable. Use meaningful names. The first character must be a letter or underscore; names cannot contain spaces; reserved keywords cannot be used. 
     Slide 9: String Variables A string is a combination of characters. A string variable can store names, phone numbers, descriptions, and other text. Example:
string productDescription = "Jamhuuriya University"; MessageBox.Show(productDescription); 
Slide 10: String Concatenation String concatenation means joining one string to the end of another. The + operator is used. Strings can also be combined with numeric values.
 Slide 11: String Variable Application This slide demonstrates how string variables can be used in a C# application to store and display text. 
 Slide 12: Declaring Variables Before Using Them Variables must be declared before they are used. You can declare a variable first and assign its value later. Example: string fullName; fullName = "Leylo Shire";
  Slide 13: Local Variables and Scope A local variable is declared inside a method. Scope is the part of a program where a variable can be accessed. Lifetime is the period during which it exists in memory. A local variable is created when its method starts and destroyed when the method ends.
   Slide 14: Duplicate Variable Names You cannot declare two variables with the same name in the same scope. Variables with the same name can exist in different methods. Assignment compatibility means a value must match the variable’s data type. 
   Slide 15: Initializing Variables Initialization means assigning an initial value to a variable. A local variable must have a value before it is used; otherwise, the compiler produces an error.
    Slide 16: Declaring Multiple Variables You can declare multiple variables of the same data type in one statement, and you can initialize them together. Example: string firstName, lastName, middleName;
     Slide 17: Numeric Data Types and Variables Numeric data types are used to store numbers and perform mathematical operations. int stores whole numbers; double stores real numbers including decimals; decimal stores real numbers with greater precision and is commonly used for financial applications. 
     Slide 18: Numeric Literals A numeric literal is a number written directly in program code. Whole number literals are treated as int; numbers with decimal points are treated as double; decimal literals use m or M at the end.
      Slide 19: Assignment Compatibility for int An int variable can receive an int value. It cannot directly receive a double or decimal value. 
      Slide 20: Assignment Compatibility for double A double variable can receive a double or int value. It cannot directly receive a decimal value.
      Slide 21: Assignment Compatibility for decimal A decimal variable can receive a decimal or int value. It cannot directly receive a double value.
       Slide 22: Explicit Conversion with Cast Operators Type casting means explicitly converting a value from one data type to another. The cast operator is the target type in parentheses. Example: decimal moneyNumber = 4500m; int wholeNumber = (int)moneyNumber; 
       Slide 23: Declaring Local Variables with var The var keyword allows the compiler to determine a variable’s data type automatically. This is called type inference. A var variable must be initialized and can only be used for local variables. Slide 24: Performing Calculations C# arithmetic operators: + addition; - subtraction; * multiplication; / division; % modulus, which returns the remainder.
        Slide 25: Rules for Performing Calculations A math expression performs a calculation and produces a value. Follow the order of operations and use parentheses when needed. int with double produces double; int with decimal produces decimal; double with decimal is not allowed directly.
         Slide 26: Integer Division Integer division occurs when an integer is divided by another integer. The result is an integer, so the fractional part is removed. Convert one operand to double to obtain a decimal result. int x = 7, y = 3; int result = x / y; // result is 2 double answer = (double)x / y; 
         Slide 27: Inputting and Outputting Numeric Values TextBox input is treated as a string, even when it looks like a number. Convert it to a numeric data type before calculations. Parse methods include int.Parse(), double.Parse(), and decimal.Parse().
          Slide 28: Numeric Input/Output Example This slide demonstrates an application that receives numeric input, processes values, and displays a result. The key concept is converting user input into numeric data before calculations. Slide 29: Displaying Numeric Values A TextBox or Label Text property accepts strings. Use ToString() to convert a numeric value into a string for display. A number can also be combined with a string using +. 
          Slide 30: Formatting Numbers with ToString ToString() can format numbers: N for number format; F for fixed-point format; E for exponential format; C for currency; P for percentage. double number = 12.3; number.ToString("N3"); Slide 31: Simple Exception Handling An exception is an unexpected error during program execution, such as dividing by zero, opening a missing file, or entering invalid data. Exception handling lets the program respond instead of stopping unexpectedly.
          Slide 32: Handling Exceptions with try-catch The try block contains statements that may cause an exception. The catch block contains statements that respond when an exception occurs. try { // Statements that may cause an error } catch { // Handle the error }
           Slide 33: Throwing an Exception Throwing an exception means an error occurs during execution. For example, nonnumeric TextBox input may cause double.Parse() to throw an exception.
            Slide 34: Throwing vs. Catching Exceptions Throwing means an error occurs and an exception is raised. Catching means the program handles the exception. Example: an ATM raises an invalid-PIN error, then displays a message asking the user to try again. 
            Slide 35: Displaying an Exception’s Default Message An exception is an object. Its Message property contains a description of the error. Use catch (Exception ex) and MessageBox.Show(ex.Message) to display it. 
            Slide 36: Practice with Class This slide provides a practical exercise for applying exception-handling concepts.
             Slide 37: Solution — The Code This slide presents the solution to the exception-handling practice exercise. The main concept is applying try-catch to handle unexpected errors. 
             Slide 38: Using Named Constants A named constant is a name representing a value that cannot change during program execution. Constants are declared using the const keyword. const double INTEREST_RATE = 0.129; 
             Slide 39: Declaring Variables as Fields A field is a variable declared at class level, inside a class but outside any method. Its scope is the entire class. It is created when the form or object is created.
              Slide 40: The FieldDemo Application This slide demonstrates how a field can be used in a Windows Forms application and accessed by different methods within the same class.
               Slide 41: FieldDemo Code Example The example uses a name field. Different button event handlers can change its value, and another button can display its current value. A field can be accessed by multiple methods in the same class.
                Slide 42: Using the Math Class The .NET Math class provides methods: Math.Sqrt(x) returns a square root; Math.Pow(x,y) raises x to a power; Math.Max(x,y) returns the greater value; Math.Min(x,y) returns the smaller value; Math.Round(x) rounds to the nearest integer. Math.PI represents the circle ratio, and Math.E represents the natural logarithmic base.
                Slide 43: More GUI Details — Tab Order Focus means a control is receiving keyboard input. Tab order is the order in which controls receive focus when Tab is pressed. TabIndex determines a control’s position; the first control has index 0. 
                Slide 44: Tab Order (1 of 2) You can set tab order by selecting Tab Order from Visual Studio’s View menu and clicking controls in the desired order. Labels do not receive keyboard input and cannot receive focus.
                 Slide 45: Tab Order (2 of 2) The Focus() method moves keyboard focus to a specific control. nameTextBox.Focus(); 
                 Slide 46: Assign Keyboard Access Keys to Buttons An access key, or mnemonic, lets users access a control using Alt plus a letter. Add an ampersand (&) before a letter in the button’s Text property. &Exit;
                  Slide 47: Setting Colors BackColor sets a form or control’s background color. ForeColor sets text color. These properties support color values such as Color.Black and Color.Yellow. messageLabel.BackColor = Color.Black; messageLabel.ForeColor = Color.Yellow; 
                  Slide 48: Background Images for Forms (1 of 2) A Form’s BackgroundImage property displays an image as its background. BackgroundImageLayout determines how the image appears. 
                  Slide 49: Background Images for Forms (2 of 2) None displays the original image size; Tile repeats it; Center places it in the center; Stretch fills the form by stretching; Zoom resizes while preserving proportions.
                   Slide 50: GroupBoxes versus Panels GroupBox and Panel are container controls. GroupBox can display a title and has a Text property. Panel cannot display a title and has no Text property, but supports BorderStyle.
                    Slide 51: Debugger and Logic Errors A logic error allows an application to run but produces incorrect results. Examples include mathematical errors or assigning the wrong value to the wrong variable. Visual Studio debugging tools help locate these errors. 
                    Slide 52: Breakpoints (1 of 2) A breakpoint is a selected line where program execution pauses. The application enters Break Mode, allowing you to examine variable values and control properties. Slide 53: Breakpoints (2 of 2) This slide demonstrates setting a breakpoint in Visual Studio. A red dot indicates the breakpoint; execution pauses when it reaches that line. Slide 54: Break Mode In Break Mode, the program is paused. Hover over a variable or control property in the Code Editor to examine its contents.
                    Slide 55: Locals and Watch Windows The Locals window displays variables in the current procedure with their values and data types. The Watch window displays variables you choose to monitor.
                     Slide 56: The Locals Window The Locals window displays variable names, current values, and data types to help identify incorrect values during execution. 
                     Slide 57: Single-Stepping (1 of 2) Single-stepping executes a program one statement at a time. After each statement, you can examine variable values to identify the line causing an error.
                      Slide 58: Single-Stepping (2 of 2) You can single-step using F11, the Step Into toolbar command, or Debug → Step Into in Visual Studio.
