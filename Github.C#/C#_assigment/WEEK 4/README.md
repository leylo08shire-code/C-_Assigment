Chapter 4 — Loops, Files, and Random Numbers
5.1 The while Loop A while loop repeats a statement or block as long as its Boolean condition is true. It contains a condition and a loop body. Structure of a while Loop The while clause contains the condition; statements inside braces form the body. Each repetition is an iteration. A counter variable can track repetitions. while Is a Pretest Loop A while loop checks its condition before the body. If the condition is true initially, it runs; if false, it runs zero times. Infinite Loops An infinite loop continues because its condition never becomes false. A common cause is forgetting to update a counter or condition.
 5.2 Increment and Decrement Operators ++ increases a variable by 1; -- decreases it by 1. Examples: count++; count--; They can also be written as count += 1 or count -= 1. Postfix vs Prefix Postfix (count++) uses the old value and then increments. Prefix (++count) increments first and then uses the new value. 
 5.3 The for Loop A for loop is useful when a counter controls repetitions. It has initialization, a Boolean test, and an update expression; it is a pretest loop. for Loop Example In for (int count = 0; count < 5; count++), initialization sets count to 0, the test checks count < 5, and update adds 1 after each iteration. Other Update Expressions The update can change by more than 1 or count backward, such as count += 10 or count--. 
 5.4 The do-while Loop A do-while loop is a posttest loop: it executes the body first, then checks the condition. Therefore, it runs at least once. while vs do-while while checks before the body and may run zero times. do-while checks after the body and always runs at least once.
  5.5 Using Files for Data Storage Files preserve data for later use. Basic steps: open the file, read or write data, and close it. Text files store encoded text; binary files store non-text data. File Accessing A file object connects a program to a file. StreamWriter writes text; StreamReader reads text.Writing Data to a File Create a StreamWriter, open/create or append to a file, use Write or WriteLine, then close the file. Write vs WriteLine Write outputs data without adding a new line. WriteLine outputs data and then adds a newline. CreateText vs AppendText CreateText creates a file and erases existing contents if the file already exists. AppendText adds new data to the end without erasing existing contents. Specifying a File Location A file path can be included with the filename. The @ prefix allows a path string to use backslashes without escaping each one. Reading Data from a File Use StreamReader and File.OpenText to open a text file. ReadLine reads one line; Read reads characters; close the connection when finished. Reading a File with a Loop EndOfStream indicates whether the reader has reached the end. A loop can continue while !inputFile.EndOfStream.
   5.6 OpenFileDialog and SaveFileDialog These invisible controls display standard Windows dialogs for opening or saving files. Displaying an Open Dialog Call openFileDialog.ShowDialog() to display the Open dialog box. Detecting User Selection ShowDialog returns a DialogResult. OK means the user confirmed; Cancel means the user cancelled. FileName and InitialDirectory FileName stores the selected file’s path and name. InitialDirectory sets the folder shown when the dialog opens. Displaying a Save As Dialog Show SaveFileDialog, check for DialogResult.OK, then use the selected filename to create or save the file.
   5.7 Random Numbers The Random class generates random values. Next generates an integer; NextDouble generates a floating-point value from 0.0 up to (but not including) 1.0. Random.Next Next(max) generates an integer from 0 up to max-1. For example, rand.Next(100) produces a value from 0 through 99.
    5.8 The Load Event The form’s Load event occurs when the form is loaded into memory. Double-click the form in Designer to create its handler. Code in the Load Event Statements inside the Load event handler execute when the form launches.
