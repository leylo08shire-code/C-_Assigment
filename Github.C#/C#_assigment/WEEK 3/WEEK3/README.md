Chapter 3 — Making Decisions
4.1 Decision Structures and the if Statement A control structure determines the order in which program statements execute. A sequence runs statements in order; a decision structure runs statements only when a condition is met. The if statement uses a Boolean expression (true or false). A Simple Decision Structure A single-alternative decision has one path for true; if false, the statements inside the if block are skipped. Syntax: if (condition) { statements; } Relational Operators Relational operators compare values: > greater than, < less than, >= greater than or equal, <= less than or equal, == equal, and != not equal. An if Statement with a Boolean Expression Example: if (sales > 50000) { bonus = 500; }. The bonus is assigned only when sales is greater than 50,000.
 4.2 The if-else Statement An if-else has two alternatives. If the Boolean expression is true, the if block runs; otherwise, the else block runs.
  4.3 Nested Decision Structures Nested decisions place one if or if-else inside another. They allow a program to test a second condition only after the first decision. The if-else-if Statement This structure checks several conditions in order. The first true condition’s block executes; if none is true, the final else block can run.
   4.4 Logical Operators && (AND) is true only when both conditions are true. || (OR) is true when at least one condition is true. ! (NOT) reverses a Boolean value. Decision Structures with Logical Operators Logical operators combine or reverse conditions, for example: temperature < 20 && minutes > 12. This requires both conditions to be true. 
   4.5 bool Variables and Flags A bool variable stores true or false. A flag is a bool variable used to indicate whether a particular condition exists.
    4.6 Comparing Strings Strings can be compared with == and !=. String.Compare(name1, name2) returns 0 when the strings are equal.
     4.7 Preventing Data Conversion Exceptions TryParse methods attempt to convert input without causing a conversion exception. Examples: int.TryParse, double.TryParse, decimal.TryParse. The out parameter receives the converted value.
     4.8 Input Validation Input validation checks whether entered data is acceptable before use. TryParse checks whether input has the correct data type; validation also checks whether the value is reasonable, such as hours from 1 to 168. 
     4.9 Radio Buttons and Check Boxes Radio buttons allow one choice from a group (mutually exclusive). Check boxes allow multiple choices. Both use Text and Checked properties. RadioButton and CheckBox Controls The Checked property is Boolean. Use if (control.Checked) to test whether the control is selected. The CheckedChanged Event CheckedChanged occurs when a control’s Checked property changes. An event handler can respond to the selection change. 
     4.10 The switch Statement switch selects a path based on the value of an expression. Each case handles a value and usually ends with break. default is optional and handles unmatched values. 
     4.11 Introduction to List Boxes A ListBox displays items and lets users select one. Items stores the list; Items.Count gives its size; SelectedItem gives the chosen item; SelectedIndex gives its zero-based position. Adding Items to a ListBox Use ListBox.Items.Add(item) to add an item. Example: daysListBox.Items.Add("Monday"); SelectedItem and SelectedIndex List indexes start at 0. SelectedIndex is -1 when nothing is selected. Check it before accessing SelectedItem to avoid an exception. Text vs SelectedItem Text provides the selected text as a string. SelectedItem provides the selected object and is useful when the list contains data objects. Removing Items from a ListBox Items.Remove(item) removes a matching item. Items.RemoveAt(index) removes the item at a particular valid index. Items.Clear() removes all items.
